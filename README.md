# Reusable Studio Engine

A reusable vanilla JavaScript Canvas template for starting creative coding projects quickly and intentionally.

## What this is

This repository is my starting point for future creative coding assignments.

It provides:

- A working Canvas sketch
- HiDPI scaling
- An animation loop
- Mouse input
- Modular JavaScript files
- A planning/documentation system
- A process screenshot system
- A GitHub Pages deployment path
