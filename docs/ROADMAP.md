# Roadmap

This is the ritual I will use when starting a new assignment.

1. Define intent and constraints.
2. Write the idea in words before coding.
3. Identify the signal, parameter, and behavior.
4. Sketch the system architecture.
5. Build the smallest working version.
6. Run the system and check the visible behavior.
7. Iterate through visible tests.
8. Capture screenshots at meaningful milestones.
9. Deploy the working version.
10. Polish documentation only after the meaning is legible.
